## Cost Analysis

Scenario A cost approximately $1.92 per month.

Scenario B cost approximately $2233.80 per month.

The numbers matched the estimates from the Azure Pricing Calculator. The biggest difference between the two scenarios was the use of a GPU virtual machine running continuously, which dramatically increased the monthly cost.

I was surprised by how expensive GPU resources can be compared to a small virtual machine. Even a simple cloud setup can become costly if high-performance resources run 24/7.

While exploring the Azure Pricing Calculator, I also looked at storage and database services. It was interesting to see how storage costs remained relatively low compared to compute resources, while managed databases added additional monthly costs depending on size and performance requirements.
