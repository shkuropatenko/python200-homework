## Cost Analysis

Scenario A was inexpensive because it used a very small virtual machine for a limited number of hours.

Scenario B was much more expensive because GPU virtual machines are designed for heavy AI and machine learning workloads and run continuously.

The pricing calculator helped compare cloud infrastructure costs and showed how quickly costs increase when using high-performance resources.

The Python script calculated estimated monthly costs using hourly pricing rates from the Azure calculator.
